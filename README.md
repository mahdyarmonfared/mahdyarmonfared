## 🧭 About Me

I am a **Frontend Engineer & Creative Web Developer** passionate about deconstructing complex digital architectures to first principles. I eliminate bloated boilerplate, optimize for microsecond performance, and craft bespoke, immersive interactive experiences with dark cinematic aesthetics.

- 🚀 **Currently Running:** The **[30 Repos in 30 Days Challenge](https://github.com/mahdyarmonfared)** — building, testing, and shipping 30 production-ready open-source developer utilities and web apps in 30 consecutive days.
- 🎨 **Creative Web Focus:** High-frame-rate animations, custom physics engines, Web Audio API synthesis, and pixel-perfect design systems.
- 🛠️ **Systems & CLI:** Zero-dependency Node.js CLI tools, instant REST mock servers, real-time HTTP monitors, and AppSec guardians.
- 🌐 **Bilingual Architecture:** Deep native support for Right-to-Left (Persian) and Left-to-Right (English) typography and layout math.
